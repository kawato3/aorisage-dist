# aorisage-dist

This repository is used only for public release artifacts for aorisage.

- Product site: https://aorisage.pages.dev/
- Source repository: https://github.com/kawato3/aorisage
- Downloads: use the GitHub Releases page in this repository.

Only signed and notarized macOS `.pkg` installer assets are published here. Source code and development history stay in the main aorisage repository.

The installer includes selectable VST3, AUv2, AAX, and CLAP plug-in formats for macOS.

Use of the distributed installer is subject to the EULA included in the package.
